# Personal AI Knowledge Assistant

## Overview

A privacy-first AI system that ingests personal documents, notes, emails, and learning materials and provides conversational access to the entire knowledge base using Retrieval-Augmented Generation (RAG).

## Features

- Document Ingestion
- Semantic Search
- Vector Database
- Retrieval-Augmented Generation
- Source Citations
- Local LLM Support
- Privacy-Focused Architecture

## Tech Stack

- Python 3.11
- FastAPI
- Streamlit
- LangChain
- FAISS
- Sentence Transformers
- Ollama
