# Project Scope

## Problem

Personal information is scattered across PDFs, notes, emails, books, and learning materials.

Users struggle to retrieve insights from information consumed over long periods.

## Solution

A Personal AI Knowledge Assistant capable of:

- Ingesting documents
- Building embeddings
- Storing vectors
- Retrieving relevant information
- Generating cited responses

## Objectives

- Build a local RAG system
- Ensure privacy of personal data
- Provide conversational search
- Support multiple document formats

## Expected Outcome

An AI assistant capable of answering questions based on a user's personal knowledge repository.
